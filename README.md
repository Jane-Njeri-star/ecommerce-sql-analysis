# e commerce-sql-analysis
E-commerce Sales Analysis (SQL + Power BI)



##  Project Overview
This project analyzes e-commerce sales data to uncover revenue trends and business insights using SQL and Power BI.

##  Data Cleaning
- Cleaned and standardized multiple tables
- Handled inconsistent and messy data
- Prepared dataset for analysis

##  Analysis Performed
- Monthly revenue trends
- Month-over-month growth using LAG()
- Revenue fluctuations and pattern identification

##  Key Insights
- Revenue fluctuates significantly across months
- Certain months show strong growth, while others experience declines
- Drops after peak months suggest potential retention issues
- Indicates opportunity for improved demand consistency and forecasting

##  Tools Used
- SQL (MySQL)
- Power BI
